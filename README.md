# Mój stack AI

Narzędzia, które podłączam do Claude, i prompt do podłączenia każdego z nich. Opis z instrukcją: https://www.bartbakowski.com/wiedza/moj-stack-ai

## Jak używać

1. Otwórz plik narzędzia w folderze `narzedzia/`.
2. Skopiuj prompt z sekcji „Prompt do Claude Code” i wklej go w Claude Code.
3. Claude przeprowadzi Cię przez podłączenie i sprawdzi, czy działa.

Ceny i sposoby podłączenia sprawdzone na stronach producentów w listopadzie 2026. Zmieniają się, więc przed zakupem zajrzyj na stronę narzędzia.
